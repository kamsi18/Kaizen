DEVICE USAGE ACCESS

Phone-wide tracking needs a native app.

A website cannot ask Android or iOS for permission to read time spent in other apps. This preview does not collect that data. You can enter the totals shown in your phone settings above.

Android

In a native Kaizen app, grant Usage access from Settings → Apps → Special app access → Usage access. The app must request that access and explain how the data is used.

iPhone

Automatic Screen Time integrations require a signed native app with Apple’s Family Controls entitlement and the user’s authorization. A browser page cannot request it.
